# Level 5, exercise 6: file viewer, the tree in a pane

## The mod

`mods/file-viewer/` adds a `/file-viewer` command that opens a pane titled for the project. A separate `ui.render` hook draws the tree: folders first, folders open and close on a press, each file with its size. `.git` and `node_modules` are skipped.

## Choices

- Everything goes through `$`, and the mod only lists folders.
- Symbolic links are not shown, so the tree cannot lead outside the project.
- The pane opens only from the command, not at session start.
- Open folders live in `$.state`, so a reload keeps them.
- `.claude-plugin/types/` is generated by the engine for each Claude Code version, so it is ignored by git.
