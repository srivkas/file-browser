## Findings

### Aggregate views

- **Architecture delta — clean.** `src/lib` imports only `src/lib` and the two approved packages (`marked` only in `markdown.ts`); no lib→components import, no cycle (`grep "^import" src/lib/*.ts`). AD-9 props wiring held. *Accept.*
- **Spec reconciliation — four as-built deviations from the spine/UX, all deliberate:** (1) `parseMarkdown` returns `MdBlock[] | null` and `MarkdownView` falls back to plain text (spine AD-5 shows no null); (2) http(s) links with a user name or password are inert (`src/lib/links.ts`), stricter than PRD FR-14's wording; (3) `TextPreview` key is `${node.path}#text` (spine AD-3 says `node.path`) to avoid a duplicate sibling key; (4) tokens `--tab-size` and `--line-height-heading` exist in `tokens.css` but not in DESIGN.md. *Reconcile the documents (action 4).*
- **Pattern divergence:** `LocalImage.tsx` sets state through `Promise.resolve().then(…)` to satisfy `react-hooks/set-state-in-effect`; the documented pattern in `src/components/CLAUDE.md` assumes a real async source. Works and is verified; *accept, but document the pattern* (action 5).
- **Duplication:** none found beyond the intended shared helpers (`decodeEntities`, `ImagePlaceholder`).

## Action items

1. **Show "Empty file" (or the plain view) when a non-empty Markdown file parses to no blocks.** Owner: dev (next story or a small fix).
2. **Make the fallback and decoding tests deterministic:** mock `marked.lexer` to throw instead of relying on stack depth; add `&amp;lt;` single-decode cases for text, link and image paths. Owner: dev.
3. **Harden and pin the ESLint safety rules:** ban aliasing `marked`, `marked.marked`/`Parser`/`Marked`, `Object.assign`-style `innerHTML`, `srcDoc`, template-literal `import()`; add a Vitest that lints known-bad snippets with the ESLint API and asserts each rule fires. Owner: dev.
4. **Reconcile the documents to the as-built code** (proposed, not applied): spine AD-5 (`parseMarkdown` may return null → plain fallback), AD-3 (sibling-key suffix), PRD FR-14 (userinfo links inert), DESIGN.md (`--tab-size`, `--line-height-heading`). Owner: product owner.
5. **Process — implement every story through a fresh subagent from the approved spec.** Stories 1.1–1.2 (and a first pass of 1.3) were coded in the orchestrating session; the course's `bmad-build` expects a fresh subagent. 1.3–1.5 followed it. Encode as a rule for the next epic. Owner: orchestrator.
6. **Process — decide on a DOM test environment** (jsdom or happy-dom, a new dev dependency): five reviews in a row flagged untestable component behaviour (blob images, URL revocation, `TextPreview` routing). Owner: product owner (dependency approval).
8. **Wrap the Markdown preview in an error boundary that falls back to the plain view.** Owner: dev.
7. **Process — list every new design token in the story spec.** The 1.3 subagent had to invent `--line-height-heading`. Owner: orchestrator (spec writing).
